# 知识库调研

适用：用户询问 Nebula 的产品、流程、值班、API 规范、套餐等内部事实。

## 步骤

1. 把问题拆成 1–3 个关键词组合，分别调用 `search_knowledge`（不要只查一次）。
2. 对最相关的 1–2 个 doc_id 调用 `read_document`，读全文确认上下文，避免只看片段断章取义。
3. 回答时先给结论，再给依据；每个关键事实后面用 `[doc_id]` 标注来源。
4. 如果检索不到，明确说「知识库里没有」，并给出建议补充的关键词，不要编造。

## 检索技巧

- 中文查询用名词短语，例如「发布窗口」「回滚标准」「P0 响应时限」，比整句更准。
- 同义词要试：值班 / on-call；套餐 / 计费；告警 / 监控。
- 找到 doc_id 后，`read_document` 会返回完整 Markdown，其中 `##` 小节就是知识库的检索块。
